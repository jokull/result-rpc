# result-rpc brand

The identity pairs a soft, organic wordmark with a precise technical type
system. The contrast is the point: humane failure handling, robust
infrastructure, and none of the costume-like heaviness of an all-monospace UI.

## Primary logo

Use the full wordmark only. The master lockup is black with the letters knocked
out to transparency, so the surface behind the logo becomes the letter color.
On branded digital surfaces, use the direct-path Iris-blue SVG; it stays crisp
at navigation sizes and avoids resampling the knockout mask.

- `logo/result-rpc-lockup.svg` — primary scalable asset
- `logo/result-rpc-lockup-blue.svg` — crisp Iris digital lockup
- `logo/result-rpc-lockup.png` — transparent 2400 px raster
- `logo/result-rpc-wordmark.svg` — uncontained wordmark for exceptional layouts
- `logo/result-rpc-wordmark.png` — black wordmark on transparency
- `logo/result-rpc-wordmark-white.png` — reversed wordmark on transparency

Do not use the stacked `RR / PC` monogram. Do not add distress to the cleaned
Bezier outlines.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Canvas | `#F6F1E7` | Primary light background and knockout surface |
| Ink | `#111111` | Logo, body copy, code panels |
| Iris | `#2E5090` | Primary brand blue, links, major fields |
| Sky | `#A8C5D9` | Blue highlight and quiet panel source color |
| Sky soft | `#E4EDF4` | Accent backgrounds with Ink text |
| Sunflower | `#E7D28A` | Focused warm accent and selection color |
| Leaf | `#6A8B5A` | Supporting status and botanical accent |

Iris should dominate solid chromatic surfaces. Primary buttons use Iris with
warm-white text. Soft accent panels use Sky soft with Ink or Iris text.
Sunflower is a focused accent, not a second primary; Leaf is reserved for
semantic status.

## Typography

Space Grotesk is the display voice, IBM Plex Sans is the reading face, and
JetBrains Mono is reserved for code and compact technical labels. The logo is
artwork and must never be recreated as live type.
